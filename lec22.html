2 · Problem 1 — Provisioning Delay Penalty
Given: Peak demand = 120 units.
D(t) = 50·sin(t), t ∈ [0, π/2];    D(t) = 20·sin(t), t ∈ [π/2, π]
R(t) = D(t) + δ·(dD/dt),  where δ = π/12 (provisioning delay)
Cloud unit cost = 0.9 units/unit-time. Min demand = 0.
Find: Penalty cost.

Solution

First, compute ∫D(t)dt from 0 to π:

IntervalIntegralValue
[0, π/2]50∫sin(t)dt = 50[−cos(t)]₀^{π/2}50·(0 − (−1)) = 50
[π/2, π]20∫sin(t)dt = 20[−cos(t)]_{π/2}^π20·(1 − 0) = 20
Total ∫D(t)dt—70

Now compute R(t) provisioned over the same interval. δ·dD/dt adds a correction proportional to the rate of change. The net result:

R = 70 + δ × [rate integral correction] = 70 + (π/12) × 30 = 70 + 30π/12
R − D = 30π/12 ≈ 7.86 units
Interpretation: Since R > D (provisioned resources exceed demand), the penalty is paid for unused resources, not missed service. Penalty = 7.86 cost units.
Note: Network costs, maintenance costs, and other overhead are NOT included in this simplified calculation.
3 · Problem 2 — Cloud vs. Owned: Utility Premium Check
Given: Peak demand P = 100 units. D(t) = 50(1 − e^{−t}).
Baseline (owned) unit cost B = 120. Cloud unit cost C = 200.
Service period T = 100 time units.
Find: Is cloud cheaper than owned infrastructure?

Solution

QuantityCalculationResult
Utility premium UC / B = 200 / 120≈ 1.667
Average demand A(1/T)∫₀¹⁰⁰ 50(1−e^{−t})dt ≈ (1/100)×50×99≈ 49.5 units
Peak-to-average P/A100 / 49.5≈ 2.02
Condition checkU < P/A ? → 1.667 < 2.02 ?YES — Cloud is cheaper
Rule: Cloud is economically justified when U < P/A. Here, the demand function 50(1−e^{−t}) grows from 0 toward 50, so average demand is well below the peak of 100 — making the P/A ratio high enough to justify the higher cloud unit price.
Intuition: When demand is highly variable (low average relative to peak), owned infrastructure sits idle most of the time. The cloud's pay-per-use model avoids that waste, more than compensating for the higher per-unit price.

Summary
Provisioning delay penalty: R(t) = D(t) + δ·dD/dt. Penalty = ∫|D−R|dt. When R > D, you pay for idle capacity; when R < D, you miss service delivery.
Cloud cheaper condition: U < P/A. High demand variability (low average relative to peak) makes cloud attractive — owned infra sits idle when U < P/A.
Effective cost formula: Include efficiency, power, management, and capital amortization. Cloud's 80% efficiency vs. in-house 40% can offset cloud's higher per-unit price.
Break-even insight: In-house becomes economically competitive with cloud only at very high (≥90%) sustained utilization — rare in practice due to demand variability.
