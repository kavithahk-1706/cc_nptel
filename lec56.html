Lecture 56 MED priority

Cloud Computing in the 5G Era

Prof. Soumya Kanti Ghosh · Dept. of Computer Science and Engineering, IIT Kharagpur

High-level overview of how 5G networks complement and enable cloud computing — addressing its core challenges of latency, data load, and mobility. Covers the three 5G service types (eMBB, URLLC, mMTC), the generation evolution of mobile networks, and the relationship between cloud and 5G cloudification via NFV and SDN. Know the 5G service types and key terms for exams.

1 · Why 5G Matters for Cloud Computing
Foundation: Cloud computing's success depends on ubiquitous connectivity. Without it, the cloud paradigm does not work. As mobile networks become the de facto backbone for IoT devices, edge nodes, and end users, the quality of that network directly limits what cloud can deliver.

Open Challenges That 5G Addresses

Challenge
Latency and Round-Trip Delay
Data traveling from IoT sensors to the cloud and back faces high round-trip delay, especially over mobile networks. Fog and edge computing move processing closer to the device, but the backbone network quality still determines end latency. 5G targets ~1 ms latency.
Challenge
Massive Data Load
Billions of IoT devices, live streaming, drones, and sensors generate enormous data volumes. Pushing all of it to the cloud for analysis creates massive network congestion. 5G promises multi-Gbps data rates and massive network capacity.
Challenge
Mobility
User devices, IoT sensors, and even fog nodes can be mobile. Cloud services must follow the user. 5G's architecture is designed for seamless handoffs and supports mobile edge computing natively.
Challenge
Real-Time Applications and QoS
Gaming, healthcare, autonomous vehicles, and telemedicine demand high availability and ultra-low latency. Different application types require different QoS levels. 5G manages heterogeneous traffic with QoS differentiation built into the network.
2 · 5G Overview and Generation Evolution
5G (Fifth Generation Mobile Network): A new global wireless standard designed to connect virtually everything — machines, objects, devices — everywhere, with high data rates, ultra-low latency, massive capacity, increased availability, and more uniform user experience.

Three Main 5G Service Types

eMBB
Enhanced Mobile Broadband. Better smartphones, immersive VR/AR, faster uniform data rates, lower cost per bit. Makes interactive multimedia feasible at scale.
URLLC
Ultra-Reliable Low-Latency Communication. Autonomous vehicles, smart grids, remote patient monitoring, telehealth, industrial automation. Mission-critical applications where failure is unacceptable.
mMTC
Massive Machine Type Communication. Seamlessly connects billions of embedded IoT sensors. Smart cities, smart agriculture, asset tracking, smart homes, energy monitoring. Lean, low-cost connectivity at scale.
Why 5G = win-win for cloud: 5G directly addresses the three core cloud-delivery challenges — high data rate (data load), ultra-low latency, and mobility support. Every feature of 5G makes the cloud-fog-edge-IoT continuum more practical and more commercially viable.
3 · 5G and Cloud Computing — Mutual Influence
Relationship: 5G and cloud are not competing — they are cooperative and mutually reinforcing. Each influences the development of the other in two directions.
Cloud Evolves for 5G
DirectionCloud must meet 5G network needs
HowGrowing role of edge, mobile edge, and fog computing in the cloud paradigm
GoalBring computation closer to the device, reducing latency for 5G-enabled services
ResultCloud computing = cloud + fog + edge + IoT + MCC + MEC together
5G Undergoes "Cloudification"
Direction5G infrastructure becomes software-defined
NFVNetwork Function Virtualization — network functions run as software VMs
SDNSoftware Defined Networking — control plane separated from data plane

Network as a Platform: 5G is positioned as a platform for enterprise services — "Network as a Platform." Service orchestration (coordinating bundles of services to achieve a business goal) becomes central: on-the-fly service composition, traffic classification, QoS-aware routing, all delivered through a 5G backbone with enormous capacity.
4 · Mobile Edge Computing (MEC) in 5G
MEC: Brings cloud capabilities near the end user — a mini-cloud at the edge of the mobile network. Overcomes the high latency of traditional cloud by processing data locally. Preferred for wireless communication required by next-generation applications.

MEC Applications Enabled by 5G

Healthcare and Telemedicine — remote patient monitoring, real-time diagnostics Entertainment — VR/AR/MR, gaming, immersive media Tactile Internet — ultra-responsive haptic interactions over the network IoT Factories — smart factories with massive connected sensors Emergency Response — low-latency coordination in disaster scenarios Intelligent Transportation Systems (ITS) — autonomous vehicles, traffic management
Why these need MEC + 5G: These applications are computationally intensive, generate high data volumes, and require ultra-low latency + high throughput QoS. Traditional cloud introduces too much round-trip delay. Edge computing reduces latency; 5G provides the high-capacity, low-latency mobile backbone to make it practical.
5 · Mobile Cloud Computing (MCC) in 5G
MCC (Mobile Cloud Computing): A cloud computing paradigm where mobile devices are first-class citizens. Applications are delivered to and from mobile devices. The backbone is the mobile network; cloud handles heavy computation and storage; the mobile device handles interaction.
Feature
Resource Sharing
Mobile applications share cloud resources. Compute-intensive processing is offloaded from the device to the cloud — the mobile device remains responsive without needing its own heavy CPU/GPU.
Feature
Reliability via Cloud Backup
Data is backed up and stored in the cloud, not only on the device. Loss or theft of the mobile device does not mean loss of data. Cloud stores the state; device only handles the session.
Architecture
Mobile → Base Station → Cloud
Mobile devices connect via base stations (5G radio access points) to mobile cloud infrastructure. 5G's increased bandwidth and lower latency between device and base station dramatically improves this flow.
5G Impact
Enhanced Data Sharing and Throughput
5G gives MCC the backbone it needs: high data rates for uploading large data to cloud, low latency for real-time offloading, and QoS management for mixed traffic types (interactive + bulk + streaming).
Summary
5G service types: eMBB (enhanced mobile broadband — VR/AR, smartphones), URLLC (ultra-reliable low-latency — autonomous vehicles, telehealth), mMTC (massive machine type communication — IoT, smart cities). These three together address all major application classes.
5G + Cloud = win-win: 5G provides the ubiquitous, high-capacity, ultra-low-latency backbone that cloud computing depends on. Every cloud paradigm (cloud/fog/edge/IoT) becomes more viable and more commercially feasible with 5G in place.
5G Cloudification: 5G itself is becoming software-defined via NFV (Network Function Virtualization) and SDN (Software Defined Networking) — the network infrastructure is virtualized, not just the compute. This brings 5G infrastructure management into the same paradigm as cloud computing.
MEC vs. MCC: MEC (Mobile Edge Computing) brings cloud capability to the network edge — near the user. MCC (Mobile Cloud Computing) puts mobile devices at the center of the cloud computing paradigm. Both are enabled and enhanced by 5G. MEC addresses latency; MCC addresses compute offloading and data reliability.
Service Orchestration: As applications become bundles of microservices with different QoS needs, end-to-end orchestration across cloud/fog/edge becomes critical. 5G as "Network as a Platform" provides the substrate to make dynamic, on-the-fly service orchestration practical.
