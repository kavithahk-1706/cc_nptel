Docker Container Demo

Prof. Soumya Kanti Ghosh · Dept. of Computer Science and Engineering, IIT Kharagpur

Live demo session — installs Docker Engine on Ubuntu, verifies with the hello-world container, and previews the MySQL + phpMyAdmin demo to follow. Almost no new conceptual content; all key Docker concepts are in Lecture 48. Skim for the demo flow and installation command outline only.

1 · Demo Objective
Core demonstration: Show Docker's portability claim end-to-end. Configure a MySQL database (with phpMyAdmin frontend) on an Ubuntu system, package the modified state as a Docker image, transfer it to a Windows machine, and run it there — without any separate installation at the destination.
Traditional MySQL Transfer
At destinationSeparate installation: MySQL, Apache web server, PHP, phpMyAdmin
Data transferBackup MySQL data at source → transfer → restore at destination MySQL
ExpertiseRequires configuration expertise at both ends
EffortHigh — many steps, failure points
Docker-Based Transfer
At destinationOnly Docker Engine needed — nothing else to install
Data transferSave Docker image (includes data + config) → transfer image file → load at destination
ExpertiseDocker Engine at destination; no MySQL/Apache/PHP knowledge required
EffortLow — load image → start running
2 · Demo Application: MySQL + phpMyAdmin
Backend
MySQL Docker Image
Open-source relational database; widely used. Official Docker image pulled from Docker Hub. Demo modifies this image — creates tables, adds records — then saves the modified image for transfer.
Frontend
phpMyAdmin Docker Image
Web-based GUI that connects to a MySQL backend. Pulled directly from Docker Hub without modification. Allows viewing and manipulating MySQL data through a browser interface.
Demo flow: (1) Pull both images from Docker Hub on Ubuntu → (2) Run as containers → (3) Connect phpMyAdmin to MySQL → (4) Create table, add records → (5) Save modified MySQL image → (6) Transfer image to Windows machine → (7) Load and run on Windows — same data, same config, no reinstallation.
3 · Docker Engine Installation on Ubuntu
Reference: Full installation instructions are at docs.docker.com. The steps shown in the demo follow the official documentation.

Verification: docker run hello-world pulls the hello-world image from Docker Hub (since it's not present locally), runs a container, and prints "Hello from Docker!" — confirming the Docker Engine is installed and working correctly.
4 · Docker Hub — Image Repository
Docker Hub is the public registry maintained by Docker Inc. — the central place to find, share, and distribute container images. Standard official images (MySQL, Apache, Nginx, etc.) are tested and available to pull directly.
Image pull behavior: When docker run <image-name> is called and the image is not present locally, Docker automatically pulls the latest version from Docker Hub. If the image is already cached locally, it runs from the local copy.
Other registries: Images can also come from private registries or other public registries — Docker Hub is the default but not the only source.
Summary
Demo goal: Demonstrate Docker's portability — configure MySQL + phpMyAdmin on Ubuntu, save as image, transfer to Windows, run without reinstalling anything at the destination.
Installation: Docker Engine is installed via apt on Ubuntu, following docs.docker.com. Verified with docker run hello-world — success means the engine is ready for use.
Docker Hub: Public registry where official images (MySQL, phpMyAdmin, hello-world, etc.) are hosted. docker run automatically pulls from Hub if the image is not cached locally.
