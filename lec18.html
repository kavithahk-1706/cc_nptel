Azure Demo — Python Web App Deployment

Prof. Soumya Kanti Ghosh · Dept. of Computer Science and Engineering, IIT Kharagpur

Live demo deploying a Python Flask "Hello World" app to Microsoft Azure via Azure Cloud Shell and local Git. No new conceptual content — purely a practical walkthrough. The deployment sequence is the only exam-relevant takeaway and is captured below.

1 · Azure Key Concepts from Demo
Resource Group
Logical container
A resource group is a logical container in which Azure resources (web apps, databases, storage accounts) are deployed and managed together.
App Service Plan
Hosting configuration
Specifies the location, size, and features of the web server that hosts the application. Determines the pricing tier and compute resources available.
Web App
Hosting space + URL
A Web App provides the hosting space for code and a public URL (<name>.azurewebsites.net) to access the deployed application.
Deployment User
FTP/Git credentials
A deployment user provides authentication for FTP and local Git deployment to a web application. Required before pushing code.
2 · Deployment Sequence (Flask App to Azure)
Demo walkthrough: Deployed a Python Flask "Hello World" app using local Git as the deployment method. Azure supports alternatives: FTP, GitHub, Visual Studio Online.
StepCommand / ActionPurpose
1. Clone appgit clone <github-url>Get sample Flask app code locally in Azure Cloud Shell
2. Run locallypip install flask → python main.py → localhost:5000Verify app works before deploying
3. Deployment useraz webapp deployment user setCreate username/password for Git push authentication
4. Resource groupaz group create --name --locationCreate logical container for all Azure resources
5. App Service planaz appservice plan createDefine hosting server size and location
6. Web appaz webapp create --nameCreate the app → get <name>.azurewebsites.net URL
7. Configure Pythonaz webapp config appsettings setTell Azure this is a Python app (set Python version)
8. Local git configaz webapp deployment source config-local-gitEnable Git-based deployment, get remote URL
9. Add remotegit remote add azure <url>Connect local Git repo to Azure deployment endpoint
10. Deploygit push azure masterPush code to Azure → app goes live
11. UpdateEdit code → git commit → git push azure masterRedeploy updated code; changes reflect immediately
Summary
Demo lecture — no new theory. Azure PaaS deployment: Resource Group → App Service Plan → Web App → configure runtime → local Git push to deploy. This workflow is the same pattern for any PaaS cloud platform.
Resource Group = logical container for Azure resources. App Service Plan = server spec. Web App = hosted app + public URL. All managed together.
